# Project-A Review Rules（PA-REV-*）

- **PA-REV-001** Reviewer 必須獨立檢查 task-introduced diff、未追蹤檔、相鄰呼叫與 Spec，不只相信 Coding 摘要。
- **PA-REV-002** Blocking 包括需求錯誤、重要測試缺漏、安全問題與未核准的相容性破壞。
- **PA-REV-003** Finding 須有 Rule ID、檔案／行號、可驗證證據、影響及建議；純風格改善標 Non-blocking。
- **PA-REV-004** Reviewer 唯讀，不修 Code；缺失交 Manager 安排 Coding 修復。
